# PCOS Diagnosis Project

This project focuses on a PCOS diagnosis data set from Kaggle.com. It is compiled of 1000 patients and five variables which are typically associated with PCOS diagnosis and its risks. These variables are age, BMI, menstrual irregularity, testosterone level, and number of antral follicles. Finally, the response variable is whether a patient has been diagnosed with PCOS or not, making it a classification data set.

The goal of this project was to test different machine learning algorithms on the data and compare their accuracy.
